# Zoom Workspace MVP UI/UX Prototype — Complete Figma Make Prompt Blueprint

## Project Goal

Create a professional MVP prototype inspired by the UI/UX structure of the Zoom Workspace application.

This project is ONLY for UI and UX prototype purposes.
No real backend functionality is required.
No real video calling system is required.
Do NOT design the actual in-call meeting interface.

The focus is:

* Professional UI layout
* Realistic user flow
* Consistent Zoom-style branding
* High-quality modern SaaS design
* Desktop and mobile responsiveness
* Smooth prototype navigation
* AI assistant side panel on desktop
* Proper spacing, typography, hierarchy, and interaction states

---

# MASTER DESIGN RULES

## Brand Style

Follow the exact visual direction of Zoom Workspace.

### Primary Colors

* Zoom Blue: #0B5CFF
* Deep Blue Accent: #0056D2
* White: #FFFFFF
* Light Gray Background: #F7F9FC
* Border Gray: #E5E9F2
* Dark Text: #1F2937
* Secondary Text: #6B7280

### Typography

Use modern clean sans-serif typography similar to:

* Inter
* SF Pro Display
* Helvetica Neue

Typography hierarchy:

* Main headings: Bold / 28–36px
* Section headings: SemiBold / 20–24px
* Body text: Regular / 14–16px
* Caption text: 12–13px
* Button labels: Medium / 15–16px

### Spacing Rules

* Maintain consistent 8px grid spacing system.
* Large containers should have generous whitespace.
* Use rounded corners between 12px and 20px.
* Cards should use soft shadows.
* Inputs should be large and accessible.

### Motion Style

Prototype interactions should feel:

* Smooth
* Clean
* Modern
* Minimal
* Fast

Use:

* Fade transitions
* Slide-up mobile transitions
* Soft hover effects
* Button elevation on hover

Avoid:

* Heavy animations
* Complex effects
* Overly colorful gradients
